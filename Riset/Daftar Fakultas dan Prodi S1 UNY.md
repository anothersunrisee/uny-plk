# Daftar Fakultas dan Program Studi (S1) Universitas Negeri Yogyakarta (UNY)

> **Sumber Resmi**: [PMB UNY - Program Sarjana (S1)](https://pmb.uny.ac.id/program-sarjana)  
> **Data**: Daya Tampung (SNMPTN/SNBP, SBMPTN/SNBT, Seleksi Mandiri), Akreditasi, Kelompok Ujian (SAINTEK / SOSHUM), dan Animo Pendaftar.

## Ringkasan Rekapitulasi S1 UNY
- **Total Fakultas**: 7 Fakultas Utama (+ Fakultas Kedokteran baru)
- **Total Program Studi S1**: 60 Program Studi
- **Sebaran Rumpun Ilmu**:
  - **Kelompok SOSHUM**: 4 Fakultas (FIPP, FBSB, FISHIPOL, FEB) — 33 Program Studi
  - **Kelompok SAINTEK**: 3 Fakultas (FMIPA, FT, FIKK) — 27 Program Studi

## Catatan Keterangan Simbol & Syarat Khusus
- **1) Portofolio Keterampilan**: Program studi yang mewajibkan unggah dokumen portofolio keterampilan / karya seni / uji fisik olahraga saat seleksi.
- **2) Tidak Buta Warna**: Program studi yang mensyaratkan calon mahasiswa tidak buta warna (parsial maupun total).
- **3) Tinggi Badan Minimal**: Putra minimal **160 cm**, Putri minimal **155 cm**.
- **4) Kelas Internasional / Unggulan**: Tersedia kelas bilingual / internasional (*International Undergraduate Program* / IUP).
