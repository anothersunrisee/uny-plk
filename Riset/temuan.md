## LOG #001 — Aturan Komposisi Tim dari Panduan Resmi UNY

**Tanggal**: 29 September 2026 | **Sumber**: Panduan PLK 2025 UNY + UNY Mengabdi Panduan Lengkap

| 5W1H | Isi |
|------|-----|
| **What** | Wajib min. 3–4 Prodi berbeda, min. 2 mahasiswa per prodi |
| **Who** | Semua anggota tim + ketua yang mengatur formasi |
| **When** | Sebelum pendaftaran resmi di dashboard PLK |
| **Where** | Panduan resmi PLK UNY 2025, Bab Komposisi Kelompok |
| **Why** | Jika dilanggar, pendaftaran ditolak sistem |
| **How** | Dengan 4 PTI → butuh min. 2 prodi lagi, masing-masing min. 2 orang |

### Implikasi untuk Tim
- Tim saat ini: 4 PTI = 1 prodi saja → belum memenuhi syarat
- Butuh: min. 2 prodi lagi, masing-masing 2 orang
- Contoh VALID: PTI(4) + Ilkom(2) + Manajemen(2) + TI(2) = 4 prodi
- Contoh INVALID: PTI(4) + TI(6) = hanya 2 prodi

| --------- | ------------------------------------------------------------------------------ |

| **How**   | Tetapkan jabatan setelah rekrutmen selesai, formalkan di rapat perdana         |

### Struktur Rekomendasi

```
KETUA          — PTI (kamu)
WAKIL KETUA    — Manajemen
SEKRETARIS     — Ilmu Komunikasi
BENDAHARA      — Manajemen

DIV. PROGRAM KERJA (3): PTI + PTI + TI/Ilkom
DIV. HUMAS (1): Ilmu Komunikasi
DIV. PDD (2): Pend. Seni Rupa + PTI cewek
```

### Keputusan Merge Jabatan

| Merge | Keputusan | Alasan |
|-------|:---------:|--------|
| Sekretaris + Humas | Bisa | Jika Ilmu Komunikasi handle keduanya |
| PDD + Program Kerja | Bisa | PTI bisa ikut dokumentasi teknis |
| Bendahara + Wakil Ketua | Hati-hati | Beban ganda, rawan miss |
| Bendahara standalone | Wajib | Pertanggungjawaban finansial ke DPL |
