# 🏕️ Dashboard Eksekusi PLK (Fase Lapangan)

> **Status:** 🚧 *Work in Progress* (Fase ini akan aktif setelah pendaftaran dashboard UNY di-ACC dan penerjunan dimulai pada Februari 2027).

Folder `03 - Fase PLK` ini khusus disiapkan sebagai **Command Center** saat tim sudah mulai terjun ke Desa Wonosari, Klaten. Semua dokumen yang bersifat *live action* akan ditaruh di sini agar tidak tercampur dengan urusan birokrasi dan proposal.

---

## 📂 Struktur Dokumen (Coming Soon 2027)

Nantinya, folder ini akan diisi dengan:

1. **Catatan Logbook Harian / Mingguan**
   - Bukti jam kerja untuk mengejar target 272 Jam Kerja.
   - Diisi oleh Sekretaris/Masing-masing anggota setiap hari Minggu malam.
2. **Notulensi Rapat Posko (Operasional)**
   - Catatan rapat mingguan terkait keuangan, jadwal piket masak, kebersihan basecamp, dll.
3. **Notulensi Rapat Divisi (Proker)**
   - Catatan progres dari masing-masing Koor Divisi (Web Desa, Eco-Enzyme, BUMDes, Mengajar).
4. **Draft Laporan Akhir (LPJ)**
   - Dicicil sejak minggu ke-2 di lapangan agar tidak menumpuk di akhir bulan Juli 2027.
