# 📊 Matriks SPK (Sistem Pendukung Keputusan) Pendaftar Biologi

Dokumen ini berisi analisis dan skoring kandidat pendaftar dari prodi Biologi/Pendidikan Biologi untuk mengisi **2 slot** yang tersedia, menggunakan metode *Simple Additive Weighting* (SAW) sederhana.

## 🎯 Kriteria Penilaian & Bobot

Total Bobot = 100% (1.0)
Skala Nilai = 1 (Kurang) s/d 5 (Sangat Baik)

| Kode | Kriteria | Deskripsi | Bobot |
|---|---|---|---|
| **C1** | **Pengalaman & Leadership** | Rekam jejak organisasi/kepanitiaan (kampus/desa). | **30% (0.3)** |
| **C2** | **Relevansi Skill** | Skill yang berguna untuk PLK Mengabdi (Edukasi, Humas, Lingkungan). | **30% (0.3)** |
| **C3** | **Mobilitas (Kendaraan)** | Kepemilikan motor (1 = Tidak ada, 3 = Ada kendala, 5 = Ready). | **20% (0.2)** |
| **C4** | **Nilai Tambah (Strategis)** | Bonus untuk Akamsi (hemat tempat/paham medan) atau "Paket Bestie" (chemistry kuat). | **20% (0.2)** |

## 🧮 Penilaian Kandidat

### 1. Intan Milansari & Zalfa Khoirunnisa (Tim "Paket Himabio")
Keduanya mendaftar secara berpasangan/paket.

**A. Intan Milansari**
- **C1 (5):** Sangat aktif di Himabio & banyak Studi Lapangan.
- **C2 (4):** Fokus pada edukasi biologi/lingkungan & media informasi (jurnalistik).
- **C3 (5):** Motor ready.
- **C4 (5):** Mendaftar paketan (chemistry tim terjamin).
- **Skor Akhir:** `(5*0.3) + (4*0.3) + (5*0.2) + (5*0.2)` = **1.5 + 1.2 + 1.0 + 1.0 = 4.70**

**B. Zalfa Khoirunnisa**
- **C1 (5):** Kepala Bidang Himabio, portofolio event paling kuat.
- **C2 (5):** Kuat di Humas dan paham edukasi spesifik masyarakat (Toga/Media tanam).
- **C3 (3):** Ada motor tapi posisi di Kuningan (perlu *effort*/waktu untuk dikirim).
- **C4 (5):** Mendaftar paketan (chemistry terjamin).
- **Skor Akhir:** `(5*0.3) + (5*0.3) + (3*0.2) + (5*0.2)` = **1.5 + 1.5 + 0.6 + 1.0 = 4.60**

### 2. Pendaftar Perorangan

**C. Margareta Vita Ayudya**
- **C1 (4):** Aktif di kepanitiaan kampus & kepanitiaan desa (Karang Taruna).
- **C2 (4):** Minat tinggi edukasi biologi ke masyarakat.
- **C3 (5):** Motor ready.
- **C4 (5):** **Akamsi** (Dekat perbatasan Jogja-Klaten) -> _Value sangat tinggi untuk lokasi target_.
- **Skor Akhir:** `(4*0.3) + (4*0.3) + (5*0.2) + (5*0.2)` = **1.2 + 1.2 + 1.0 + 1.0 = 4.40**

**D. Almas Caesarina Rahmawati**
- **C1 (4):** Pengalaman Akademik SL & Karang Taruna.
- **C2 (3):** Menonjolkan adaptasi & kemauan belajar.
- **C3 (5):** Motor ready.
- **C4 (2):** Perorangan, domisili kost (standar).
- **Skor Akhir:** `(4*0.3) + (3*0.3) + (5*0.2) + (2*0.2)` = **1.2 + 0.9 + 1.0 + 0.4 = 3.50**

**E. Nurrahmah Fitria Ramadhani**
- **C1 (3):** Pengalaman organisasi standar.
- **C2 (3):** Kuat di manajerial/PDD.
- **C3 (5):** Motor ready.
- **C4 (2):** Perorangan, domisili kost (standar).
- **Skor Akhir:** `(3*0.3) + (3*0.3) + (5*0.2) + (2*0.2)` = **0.9 + 0.9 + 1.0 + 0.4 = 3.20**

### 🗳️ Tabel Opsi Rekrutmen (Bahan Diskusi Rapat)

Mengingat kuota prodi Biologi/Statistika **hanya 2 slot**, silakan diskusikan dan jadikan ini bahan voting bersama tim inti berdasarkan kelebihan & kekurangan tiap opsi:

| Opsi Pilihan | Kelebihan (Pros) | Kekurangan (Cons) |
|---|---|---|
| **Opsi A: Ambil Paket Intan & Zalfa** | - *Chemistry* terjamin kuat, minim konflik internal karena sudah satu paket.<br>- Track record organisasi sangat menonjol (Kabid & Staf Ahli Himabio).<br>- Portofolio event paling solid. | - Zalfa tidak punya motor *ready* di Jogja saat ini (harus dipastikan komitmen pengirimannya dari Kuningan).<br>- Mengorbankan potensi kedekatan budaya dari mahasiswa lokal. |
| **Opsi B: Ambil Margareta + (Almas / Nurrahmah)** | - Mendapatkan Margareta ("Akamsi"), ada potensi kedekatan sosiokultural dengan warga.<br>- Pengalaman Karang Taruna desa relevan untuk proker lingkungan.<br>- Ketiga kandidat ini punya motor *ready* di Jogja. | - Jarak "perbatasan Jogja-Klaten" (rumah Margareta) belum tentu dekat dengan lokasi spesifik posko PLK nanti (Klaten itu luas).<br>- Harus membangun *chemistry* dua orang asing dari nol.<br>- Harus menolak paket Intan & Zalfa. |
| **Opsi C: Ambil Margareta + (Satu dari Paket Intan/Zalfa)** | - Kombinasi seimbang: Dapat anggota pengurus inti organisasi (relasi) sekaligus potensi Akamsi. | - **Sangat Berisiko:** Anak paketan umumnya memilih mundur berdua jika salah satu tidak diterima.<br>- Berpotensi menimbulkan kesan kurang etis saat penolakan. |

**Topik Bahasan Rapat:**
1. Apakah tim lebih membutuhkan anggota dengan **portofolio kepanitiaan/event kuat (Opsi A)** atau yang punya **potensi pemahaman sosio-kultural lokal (Opsi B)**?
2. Seberapa krusial kebutuhan kendaraan pribadi yang *ready* untuk mobilitas prodi Biologi nantinya?
